## Decisiones abiertas

- `DNI_DUPLICADO` no tiene código `RN-xx` en la KB; se mantuvo el nombre ya usado por la base.
- El middleware global devuelve `400` para un `X-Rol` desconocido; los specs de ficha y cobertura exigen `403` para roles no permitidos o desconocidos. No se modificó el middleware compartido; ver la sección Verify.
- `dniLibre` es un workaround dentro del caso de uso. Si se quiere eliminar, el contrato de `PacienteRepository.guardar` debería permitir guardar el mismo `id` con su DNI actual.
- Los cuerpos de error no incluyen `aviso` porque usan el formato compartido DD-08; la ruta `/api/sim/` y la pantalla sí rotulan la simulación.
- Vale la advertencia de C-11: con `npm run build` + `npm start`, `express.static` apunta a `dist/public` y la pantalla no se sirve; ver design D12 de ese change.
